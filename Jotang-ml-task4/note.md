# 摘要
1. 新的简单网络架构--Transformer
2. 舍去循环结构(RNN/LSTM)和卷积(CNN)完全基于注意力机制，完全舍弃了递归和卷积.
3. 模型在质量上更优越,易于并行化,训练时间减少,良好泛化能力.
# 介绍(Introduction)
1. 过去主流模型:RNN/LSTM/GRU;长期是序列建模,机器翻译这类序列转导任务的方法
计算方法:沿序列符号位置串行逐步计算,上一步隐藏状态ht−1参与生成当前ht
缺陷:1.固有的顺序性质排除了训练样本的并行化;2.长序列受内存限制,批处理困难---根本:顺序计算的固有限制
2. 注意力机制的现状:成为各种任务中出色的序列建模与转换模型的重要组成部分,使得在输入或输出序列中可以无需考虑依赖距离进行建模.
局限:绝大多数场景都要搭配循环网络RNN一起使用,不可以单独
3. 提出Transformer架构
# 背景(Background)
1. 其他并行序列模型:Extended Neural GPU,ByteNet,ConvS2S
思路:都减少串行计算,用CNN卷积作为基础模块,并行计算全部位置的隐藏表示
缺点:1.捕捉远距离依赖的代价高,ConvS2S距离线形增长,ByteNet对数增长;2.远距离位置之间依赖很难学习
2. 自注意力Self-Attention:同一序列内部计算位置之间关联,已有多任务运用
# 模型架构(Model Architecture)
Transformer采用经典Encoder-Decoder编码器-解码器堆叠结构
Encoder:输入序列特征表示z
Decoder:依靠z,自回归逐个生成输出token,每一步用上一步生成的词作为输入
2.1 Encoder(编码器,N=6层完全相同的层),每层包含两个字层(1.多头自注意力;2.逐位置前馈网络);每个子层都使用残差连接 + LayerNorm;所有子层,词嵌入输出维度统一
Decoder(解码器,N=6层),在编码器两个子层基础上,增加第三个字层:编码器-解码器注意力;1.掩码多头自注意力(加mask屏蔽未来位置,无法看见还未生成的token,保证自回归特性);2.交叉注意力;3.逐位置前馈网络FFN(同样残差连接+LayerNorm)
2.2 Scaled Dot-Product Attention(缩放点积注意力)
公式 Q,K做矩阵点积-除以更号下dk做缩放--softmax得到权重--和v相乘
缩放:维度很大时,点积结果会非常大,导致softmax函数进入梯度消失,除以过后稳定训练
2.3 Multi-Head Attention(多头注意力)
 将Q,K,V通过不同的线性变换映射到多个子空间,分别计算注意力,最后拼接并线性变换得到最终输出
 优势:让模型可以同时在多个子空间学习不同类型的依赖关系
2.4 Position-wise Feed-Forward Network (FFN)
两层线性变换,中间夹着ReLU激活函数--等价两个1*1卷积
2.5 Positional Encoding(位置编码)
transformer没有RNN,CNN,本身不知道词语顺序,要手动输入位置信息
方法:用不同频率的正弦和余弦函数生成
# 为什么用 Self-Attention
1. 对比三种网络层的各项指标:每层计算复杂度,可并行计算量,长距离以来最大路径长度    对应如下:Self-Attention:O(n^2*d),O(1),O(1);RNN:O(n*d^2),O(n),O(n);CNN:O(k*n*d^2),O(1),O(logkn) 自注意力长距离依赖路径很短,更容易学习远距离依赖;序列长的时候计算更快,并行性强
# 训练策略和结果
1. 机器翻译任务
优化器:Adam+学习率Warmup(先线性增加后衰减)
正则化:Dropout应该在嵌入层+残差连接之后;Labelsmoothing(标签平滑):训练时不用硬标签,提升泛化
训练硬件
测试结果:英德/英法翻译任务上取得SOTA,且训练成本远低于之前模型
2. 模型消融实验
改变头数h,维度dk,缩放因子更号下dk,去掉缩放,性能变差,验证缩放点击的重要性;位置编码对比(正弦固定PE和可学习PE:效果几乎一致,但是正弦PE可以外推更长序列);残差,层归一化:移除后效果下滑
结论:多头注意力,缩放因子,位置编码都是模型关键组件
3. 句法分析实验
说明自注意力不只是翻译可以用,具备通用序列建模能力,长距离依赖捕捉能力强
# 结论
本文提出Transformer,一种完全基于自注意力的序列转导模型,替换编码器-解码器架构中常用的循环层
Transformer拥有更好的并行能力,建模长距离依赖时信号传播路径更短
在机器翻译任务上，它超越了此前最优模型，同时训练耗时更少
局限:随着序列长度n增长,自注意力复杂度为O(n^2)
未来工作方向:应用到图像,音频等其他模态;处理超长输入序列
